2. Màn hình chính /transactions

Khi load: dùng dữ liệu đã có trong useTransactionsStore (đồng bộ bởi syncTransactions() gọi ở app-level). Không fetch riêng khi vào trang.

Biến derived state quan trọng:

  • sorted: getFiltered() → lọc theo picker date range → sort theo sortOption
  • paginated: sorted.slice((page-1)*30, page*30)
  • groupedByDate: nhóm paginated theo ngày (chỉ khi sort là dateDesc hoặc dateAsc)
  • totals / prevTotals: tổng thu/chi kỳ này và kỳ trước (để tính trend)

getFiltered() — Logic lọc

// Thứ tự AND trong getFiltered():
1. search → description + notes (case-insensitive, || logic)
2. category !== 'all' → txn.categoryId === filters.category
3. dateFrom → txn.transactionDate >= dateFrom
4. dateTo   → txn.transactionDate <= dateTo
5. type     → txn.transactionType === type
// Sau đó: sort mặc định dateDesc (không dùng sortOption — sort ở component)

Lưu ý: getFiltered() trả về kết quả đã sort dateDesc. Sort theo sortOption được thực hiện lại trong sorted useMemo ở TransactionsPage — không xung đột vì JS sort có thể sort lại.

6.3 Đánh giá và đề xuất

🔴 Filter filters.provider chưa được kết nối
FilterBar cho phép chọn provider nhưng getFiltered() không có logic lọc theo filters.provider. Người dùng thay đổi filter provider nhưng danh sách không thay đổi. Cần thêm điều kiện vào getFiltered(): if (filters.provider !== 'all' && t.paymentInstrumentId !== filters.provider) return false.
🟡 Người dùng hardcode — chưa có multi-user
DEFAULT_USER = { initials: 'LT', color: '#059669' } hardcode trong file. Column "Người dùng" luôn hiện "LT". Cần integrate với ledger_members + profiles (đã có trong /categories detail view).
🟡 clearAll() phụ thuộc vào txns[0].ledgerId
Nếu transactions state rỗng, clearAll() early return — không xóa được DB. Nếu giao dịch đầu tiên có ledgerId sai, sẽ xóa nhầm ledger. Nên lấy ledgerId từ useLedgerStore.currentLedger.id thay vì từ data.
💡 Đề xuất: Thêm filter provider vào getFiltered()
if (filters.provider !== 'all' && t.paymentInstrumentId !== filters.provider) return false
Thêm ngay sau điều kiện filters.category hiện tại.
💡 Đề xuất: Pagination reset khi filter thay đổi
Hiện tại page chỉ reset khi sorted.length hoặc picker thay đổi. Khi thay đổi filter (provider, category, type), length thay đổi → sorted.length thay đổi → page reset tự động. OK về logic nhưng nên explicit: thêm filters vào dependency array của useEffect reset page.
