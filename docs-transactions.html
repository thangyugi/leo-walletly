2. Tổng quan trang

Trang /transactions là trung tâm quản lý tất cả giao dịch tài chính. Bố cục từ trên xuống:

  1. PageHeader: tiêu đề + số giao dịch + DateNavigator + SortDropdown + nút Import + nút Xóa tất cả
  2. 4 StatCard: Tổng thu vào / Tổng chi ra / Số lượng giao dịch / Chi tiêu trung bình
  3. FilterBar: thanh tìm kiếm + bộ lọc mở rộng (5 trường)
  4. BulkBar: thanh thao tác hàng loạt (khi có giao dịch được chọn)
  5. Bảng giao dịch: header cột + rows nhóm theo ngày (hoặc phẳng) + footer tổng
  6. Pagination: phân trang (30 giao dịch / trang)
  7. DetailPanel: panel chi tiết (portal, cạnh phải màn hình, có thể toàn màn hình)
  8. TransactionEditModal: modal chỉnh sửa (portal)

4. Hàm tiện ích

HàmMô tả
getPrevPeriod(picker) Tính khoảng thời gian kỳ trước có cùng độ dài. VD: tháng 5 → tháng 4, tuần này → tuần trước
pct(curr, prev) Tính % thay đổi: (curr - prev) / |prev| × 100. Trả về null nếu prev = 0
getTrendVsLabel(picker, lang, t) Trả về chuỗi "vs tháng trước", "vs ngày hôm qua"… theo mode và ngôn ngữ
getInitials(text) 2 chữ cái đầu viết hoa từ mô tả (VD: "Starbucks Coffee" → "SC")
fmtDateDMY(d) Định dạng ngày YYYY-MM-DD → DD/MM/YYYY (với fallback an toàn)

5. Các component

5.1 PageHeader + actions

Tiêu đề: "Giao dịch" + subtitle hiển thị tổng số giao dịch trong store.

Actions (hàng ngang, bên phải):

  • DateNavigator: bộ chọn khoảng ngày
  • SortDropdown: chọn cách sắp xếp
  • Nút Import: link đến /import, icon Upload
  • Nút Xóa tất cả: icon Trash2, màu đỏ, chỉ hiện khi có giao dịch. Hiển thị confirm() trước khi clearAll()

5.2 DateNavigator

Component từ components/ui/date-range-picker.tsx.

Kiểu PickerValue:

interface PickerValue {
  mode:  'day' | 'month' | 'quarter' | 'year' | 'custom'
  start: string   // YYYY-MM-DD
  end:   string   // YYYY-MM-DD
}

Hỗ trợ điều hướng ← → qua từng ngày/tháng/quý/năm, chọn custom range.

Mặc định: defaultPickerValue(lang) → tháng hiện tại.

5.4 StatCard (4 thẻ thống kê)

Layout: grid-cols-2 lg:grid-cols-4. Mỗi thẻ hiển thị:

  • Label (chữ nhỏ hoa)
  • Giá trị chính (số lớn, màu xanh/đỏ)
  • Sub (phụ): thông tin bổ sung
  • Trend (xu hướng): ↑/↓ + % so với kỳ trước + label kỳ so sánh

4 thẻ:

ThẻGiá trị chínhTrendMàu
Tổng thu vào +totals.income pct(income, prevIncome) Xanh lá (gain)
Tổng chi ra −totals.expense pct(expense, prevExpense) Đỏ (loss)
Số lượng giao dịch sorted.length — —
Chi tiêu trung bình −avgExpense (hoặc —) — Đỏ (nếu > 0)

trendVsLabel: chuỗi so sánh (VD: "vs tháng trước") tính từ getTrendVsLabel(picker, lang, t).

5.5 FilterBar

Đọc/ghi trực tiếp useTransactionsStore().filters qua setFilters().

Hàng trên: Tìm kiếm + toggle bộ lọc

  • Input tìm kiếm (filters.search): tìm theo description và notes (trong store)
  • Nút Filter: toggle mở rộng bộ lọc, có badge đếm số filter đang active (activeCount)
  • Nút Clear: hiện khi có bất kỳ filter nào active → resetFilters()

Hàng mở rộng: 5 bộ lọc (grid 2–3–5 cột)

TrườngStateLoại UITùy chọn

Danh mụcfilters.categorySelectTất cả + danh sách CATEGORIES
Từ ngàyfilters.dateFromInput dateYYYY-MM-DD

Lưu ý: Filter dateFrom/dateTo trong FilterBar khác với picker trong DateNavigator. DateNavigator lọc ở component level (sorted useMemo), còn FilterBar lọc ở store level (getFiltered()). Hai bộ lọc này độc lập và áp dụng song song.

5.9 DateGroupHeader

Props: date: string, expense: number, income: number

Dải phân cách giữa các nhóm ngày. Hiển thị khi sortOption là 'dateDesc' hoặc 'dateAsc'.

Nội dung: ngày (DD/MM/YYYY + thứ viết tắt theo ngôn ngữ) + tổng thu/chi/net của ngày đó.

// Định dạng ngày có thứ:
const wd = d.toLocaleDateString(lang === 'vi' ? 'vi-VN' : 'ja-JP', { weekday: 'short' })
const label = `${fmtDateDMY(date)} (${wd})`

Net = income − expense: xanh nếu ≥ 0, đỏ nếu < 0.

Chỉ hiển thị thu/chi nếu > 0 (tránh hiện "−0").

5.10 Footer tổng hợp

Nằm cuối bảng (border-t, nền sunken). Hiển thị:

  • Bên trái: tổng số giao dịch đang hiển thị + (nếu có chọn) số đã chọn và tổng giá trị
  • Bên phải: −totals.expense (đỏ) + +totals.income (xanh)

Tổng giá trị chọn (selectedTotal): tính từ sorted.filter(selected.has(id)).sum(amount), bao gồm cả dấu âm/dương tự nhiên của amount.

5.11 Phân trang (Pagination)

Hiển thị khi totalPages > 1. Gồm:

  • Thông tin: "Trang X / Y · Z giao dịch"
  • Nút ← → để chuyển trang (disabled khi ở trang đầu/cuối)
  • Nút số trang: hiển thị tối đa 5 trang, dùng window sliding để luôn hiện trang hiện tại ở giữa
const offset = Math.max(0, Math.min(page - 3, totalPages - 5))
const p = offset + i + 1   // i từ 0 đến 4

Kích thước trang: PAGE_SIZE = 30 (hằng số cố định).

page reset về 1 mỗi khi sorted.length hoặc picker thay đổi (qua useEffect).

5.12 DetailPanel (portal)

Props: txn: Transaction, onClose: () => void, onEdit: () => void

Render bằng createPortal(panel, document.body) — thoát khỏi DOM tree để tránh bị cắt bởi overflow.

Layout:

  • Mobile: panel trượt từ dưới lên (rounded-top)
  • Desktop (sm+): panel cạnh phải toàn chiều cao (sm:w-[420px] sm:h-full border-l)
  • Toàn màn hình: khi nhấn icon Maximize → w-full h-full

Header panel: nút Edit (bút) / Maximize-Minimize / Đóng (X)

Nội dung:

  • Avatar tròn (initials 2 chữ) + số tiền lớn (±, màu xanh/đỏ) + mô tả
  • Danh sách trường: Ngày / Danh mục / Tài khoản / Loại / Ghi chú (nếu có)
  • Nếu có txn.metadata: hiển thị JSON raw (collapsible, font-mono, max-h-60 overflow-y)

Footer: nút Chỉnh sửa → onEdit() mở TransactionEditModal, đóng panel.

Overlay đen mờ (bg-black/20) phía sau, click vào đóng panel.

6. Store – useTransactionsStore

Định nghĩa trong stores/transactions.ts. Sử dụng Zustand (không persist localStorage — dữ liệu đồng bộ từ Supabase mỗi session).

6.1 State

TrườngKiểuMô tả
transactions Transaction[] Toàn bộ giao dịch. Khởi tạo rỗng ([])
filters TransactionFilters Bộ lọc hiện tại. Mặc định: tất cả trường là "all" / rỗng
sortOption SortOption Cách sắp xếp. Mặc định: 'dateDesc'

6.2 Filters (TransactionFilters)

interface TransactionFilters {
  search:   string                                              // tìm kiếm text
  provider: PaymentProvider | 'all'                            // lọc theo nguồn
  category: LegacyCategory | 'all'                             // lọc theo danh mục
  dateFrom: string                                             // YYYY-MM-DD
  dateTo:   string                                             // YYYY-MM-DD
  type:     'expense' | 'income' | 'transfer' | 'all'         // loại giao dịch
}

getFiltered() áp dụng tất cả filters (AND logic) và sort mặc định dateDesc:

// Thứ tự kiểm tra trong getFiltered():
1. search → tìm trong description + notes (case-insensitive)
2. category !== 'all' → txn.categoryId === filters.category
3. dateFrom → txn.transactionDate >= dateFrom
4. dateTo → txn.transactionDate <= dateTo
5. type → txn.transactionType === type
Lưu ý: filters.provider được định nghĩa trong TransactionFilters nhưng hiện tại getFiltered() chưa lọc theo provider — FilterBar cung cấp UI nhưng logic chưa được kết nối trong store.

6.3 Actions

ActionMô tả
addTransactions(txns) Thêm mảng giao dịch (từ import). Dedup theo id. Gắn ledgerId/workspaceId. Upsert Supabase.
addTransaction(txn) Thêm 1 giao dịch (nhập thủ công). Tạo id mới. Insert Supabase.
removeTransaction(id) Xóa theo id. Delete Supabase.
updateTransaction(id, update) Cập nhật partial. Patch Supabase (chỉ các trường trong update).
bulkUpdateTransactions(updates[]) Cập nhật nhiều giao dịch cùng lúc (dùng cho auto-categorize). Batch 10 request/lần để tránh quá tải.
setFilters(partial) Merge partial vào filters hiện tại.
setSortOption(option) Đặt cách sắp xếp.
resetFilters() Đặt lại filters về DEFAULT_FILTERS.
clearAll() Xóa toàn bộ giao dịch của ledger hiện tại. Delete Supabase theo ledger_id.
getFiltered() Trả về mảng giao dịch đã lọc (không sắp xếp theo sortOption — sort thực hiện ở component).
syncTransactions(limit?) Fetch từ Supabase (mặc định 1000 giao dịch mới nhất của ledger hiện tại). Replace toàn bộ state.

Bảng: transactions

7. Luồng dữ liệu

Tải dữ liệu

App khởi động
  → syncTransactions()  (gọi từ app-level, không nằm trong TransactionsPage)
    → Supabase: SELECT * FROM transactions WHERE ledger_id = ? ORDER BY date DESC LIMIT 1000
    → set({ transactions: mapped[] })

Lọc và hiển thị

FilterBar → setFilters(partial) → store.filters thay đổi
DateNavigator → setPicker(v) → picker local thay đổi
SortDropdown → setSortOption(v) → store.sortOption thay đổi

sorted = useMemo(() => {
  const base = getFiltered()                        // áp dụng store.filters
               .filter(tx => tx.date in picker)     // áp dụng DateNavigator
  return base.sort(sortOption)                      // sắp xếp
}, [getFiltered, sortOption, picker])

paginated = sorted.slice((page-1)*30, page*30)
groupedByDate = nhóm paginated theo ngày (nếu sort là date)

Xem chi tiết

Click TxnTableRow → onView(txn) → setDetailTxn(txn)
  → DetailPanel render (portal, slide từ phải)
  → Click Chỉnh sửa → setEditingTxn(txn); setDetailTxn(null)
    → TransactionEditModal render (portal)
    → Save → updateTransaction(id, patch) → patch Supabase

Chọn hàng loạt

Click checkbox hàng → toggleOne(id)
Click checkbox header → toggleAll() (chỉ trang hiện tại)
selected.size > 0 → BulkBar hiển thị
Click Xóa → confirm() → deleteSelected()
  → forEach id: removeTransaction(id) → Supabase DELETE
