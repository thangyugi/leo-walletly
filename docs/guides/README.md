# Hướng dẫn vận hành

Các hướng dẫn từng bước cho việc quản trị Leo Walletly (Supabase, Vercel…).
Mỗi hướng dẫn là một file riêng trong thư mục này.

| Hướng dẫn | Khi nào dùng |
|---|---|
| [Xoá một người dùng](delete-user.md) | Xoá hẳn một tài khoản (đăng nhập + hồ sơ + sổ cái của họ) |

## Thêm hướng dẫn mới

1. Tạo file `ten-viec-can-lam.md` trong thư mục này (chữ thường, nối bằng `-`).
2. Dùng bố cục giống các file có sẵn:
   - **Tóm tắt**: 2–3 câu.
   - **Trước khi làm**: cần chuẩn bị gì.
   - **Các bước**: đánh số, mỗi bước một việc.
   - **Kiểm tra lại**.
   - **Ưu / nhược điểm và lưu ý**.
   - **Xử lý lỗi thường gặp**.
3. Thêm một dòng vào bảng ở trên.
