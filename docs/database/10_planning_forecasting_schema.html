3. budget_categories

Budget Line. Định mức chi tiêu (Plan) cho từng danh mục. KHÔNG LƯU số tiền thực chi (Actual) ở đây.

Plan Data
Column Type Nullable Default Description
id uuid ❌ gen_random_uuid()
budget_id uuid ❌ FK → budgets
transaction_category_id uuid ❌ FK → transaction_categories
planned_amount numeric(30,12) ❌
warning_threshold numeric(12,8) ❌ 0.80
critical_threshold numeric(12,8) ❌ 1.00
rollover_enabled boolean ❌ false
note text ✅
created_at timestamptz ❌ now()

Constraints

UNIQUE(budget_id, transaction_category_id)

Index

idx_budget_category idx_budget_transaction_category

Enterprise Design Principle

Bảng này CHỈ lưu planned_amount (Kế hoạch). Không bao giờ lưu actual_amount (Thực tế) ở đây. Số thực tế phải được tổng hợp từ các Transaction thực (Plan vs Actual Concept) để tránh tình trạng "lệch số" kinh điển.

Recommended Enterprise Tables

Phần mở rộng dành cho hệ thống Financial Planning chuyên sâu (Theo đề xuất)

budget_versions (Crucial Enterprise Upgrade)

Tách biệt quản lý các phiên bản (Version) của Budget thay vì overwrite bản hiện tại. Hỗ trợ quy trình phê duyệt (Workflow) ngân sách và so sánh Draft vs Revised vs Approved.

budgets (1) ---> (N) budget_versions (1) ---> (N) budget_categories

scenario_results

Lưu trữ kết quả cụ thể của từng Scenario (Ví dụ: Cashflow khi lương giảm 10%).

scenario_assumptions

Tách các biến số (lạm phát, lãi suất) ra bảng riêng thay vì lưu JSON để query dễ hơn.

budget_approval_history

Lịch sử phê duyệt ngân sách, phục vụ cho tài chính doanh nghiệp hoặc gia đình minh bạch.

forecast_runs

Quản lý Batch Job cho quá trình dự báo, ghi nhận thời gian chạy và số dòng xử lý.

forecast_features

Lưu trữ các Features (Đặc trưng) được dùng để huấn luyện mô hình ML (Machine Learning).

forecast_accuracy_history

So sánh Dự báo vs Thực tế sau khi kỳ dự báo kết thúc, dùng để tính MAPE và tối ưu lại Model.
