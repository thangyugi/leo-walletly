Vòng đời tài liệu

Một tài liệu (Document) đi qua chu trình: Upload → OCR → AI Extraction → Manual Review → Match Transaction → Archive. Thiết kế này loại bỏ việc nhúng thẳng ảnh vào bảng Transaction, cho phép tài liệu được xử lý bất đồng bộ (Queue) và liên kết với nhiều thực thể khác nhau (Assets, Liabilities).

Recommended Enterprise Tables

Phần mở rộng dành cho hệ thống ECM chuyên sâu (Theo đề xuất)

11. document_line_items (Crucial Enterprise Upgrade)

Tách biệt từng dòng hàng hóa (Line Items) thay vì lưu một mảng JSON. Thiết kế này đặc biệt quan trọng để biến Walletly thành hệ thống Data Analytics cho chi tiêu.

document_id, line_no, item_name, normalized_item_name, quantity, unit, unit_price, discount, tax_amount, line_total, category_id, confidence_score

12. document_templates

Quản lý biểu mẫu (Ví dụ: Template hợp đồng cho thuê nhà, Template báo giá).

13. document_classifications

Lưu trữ kết quả phân loại văn bản (Auto-tagging bởi NLP/AI).

14. document_signatures

Tích hợp e-Signature cho các tài liệu pháp lý (Khoản vay, Hợp đồng).

15. document_shares

Quản lý quyền chia sẻ tài liệu với kế toán, đối tác hoặc thành viên gia đình.

16. document_retention_policies

Quy định thời gian lưu trữ bắt buộc (Ví dụ: Hóa đơn thuế lưu 7 năm).

17. document_archive_jobs

Tiến trình nén và chuyển tài liệu cũ sang Storage giá rẻ (Cold Storage).

18. document_embeddings

Vector embeddings để hỗ trợ Semantic Search và tính năng "Chat với hóa đơn/hợp đồng".
