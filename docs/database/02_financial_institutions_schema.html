Financial Institutions

Layer kết nối với thế giới bên ngoài (Ngân hàng, Ví điện tử, Sàn giao dịch). Không lưu transaction ở đây, chỉ làm nhiệm vụ đồng bộ dữ liệu vào Transaction Engine.
