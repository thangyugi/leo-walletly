1. subscription_providers

Các tổ chức cung cấp dịch vụ đăng ký định kỳ (Netflix, Spotify, Adobe). Liên kết trực tiếp với bảng Merchants.

Master Data
Column Type Nullable Default Description
id uuid ❌ gen_random_uuid() Primary Key
merchant_id uuid ❌ FK → merchants
provider_code varchar(50) ❌
provider_name varchar(255) ❌
website varchar(255) ✅
support_email varchar(255) ✅
support_phone varchar(50) ✅
logo_url text ✅
default_currency char(3) ❌ FK → currencies
verified boolean ❌ false
active boolean ❌ true
created_at timestamptz ❌ now()
updated_at timestamptz ❌ now()

Constraints

UNIQUE(provider_code)

Index

idx_subscription_provider idx_subscription_provider_name

Kiến trúc Event Sourcing

Bảng này tuyệt đối KHÔNG lưu `price`. Khi người dùng nâng cấp từ Basic lên Premium, chúng ta chỉ cần trỏ `current_plan_id` sang Plan mới. Lịch sử thay đổi giá sẽ được lưu trong `subscription_price_history`. Đây là kiến trúc chuẩn của Stripe Billing và Chargebee.
