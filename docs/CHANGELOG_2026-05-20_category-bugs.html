BUG FIXED #1 — Trang Quản lý danh mục hiển thị số liệu không đúng tháng hiện tại

Root cause: Hàm getGroupExpense() trong groups-bento-page.tsx ưu tiên giá trị total_expense từ database view category_balances — đây là số liệu lũy kế all-time, không phải của tháng hiện tại. Ngoài ra, khi dùng monthTxns làm fallback, hàm chỉ match đúng t.categoryId === groupId (direct match duy nhất) mà bỏ qua toàn bộ các danh mục con trong cây phân cấp.

Logic trước (sai)
function getGroupExpense(groupId, balances, monthTxns) {
  const bal = balances.find(b => b.group_id === groupId)
  if (bal) return bal.total_expense  // ← all-time, không theo tháng!
  return monthTxns
    .filter(t => t.categoryId === groupId && t.transactionType === 'expense') // ← không tính con
    .reduce((s, t) => s + Math.abs(t.amount), 0)
}
Logic sau (đúng)
function getGroupExpense(groupId, allGroups, monthTxns) {
  const descendants = getDescendantIds(groupId, allGroups)   // ← toàn bộ cây con
  return monthTxns                                             // ← chỉ tháng hiện tại
    .filter(t => t.categoryId && descendants.has(t.categoryId) && t.transactionType === 'expense')
    .reduce((s, t) => s + Math.abs(t.amount), 0)
}
Các điểm thay đổi
  • Xóa tham số balances: GroupBalance[] ra khỏi signature, thêm allGroups: Group[]
  • Luôn tính từ monthTxns (đã lọc theo tháng) — không dùng DB view
  • Sử dụng getDescendantIds để gộp tất cả danh mục con vào tính toán
  • Cập nhật tất cả call-sites: featuredExpense, topGroupsForStat, GroupCard renders
  • Xóa import GroupBalance (unused) và balances khỏi store destructuring

BUG FIXED #2 — Giao dịch khớp từ khóa không hiển thị trong "Hoạt động gần đây"

Root cause: Trong group-detail-view.tsx, groupTxns chỉ bao gồm giao dịch có categoryId đã được gán vào nhóm/nhóm con (t.categoryId && descendantIds.has(t.categoryId)).
