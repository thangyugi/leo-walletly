Trang import có 2 bước, được xác định bởi biến computed step:

const step: PageStep = result && !confirmed ? 'review' : 'setup'

6. Parser engine

Module features/import/parsers.ts. Được import và gọi trực tiếp trong processFile() và reParseWithMapping().

6.1 autoDetectProvider(headers: string[]): PaymentProvider | null

Nhận mảng header CSV (đã split theo dòng đầu tiên), khớp với pattern đặc trưng từng provider.

ProviderPattern header nhận diện
PayPay"利用日", "利用金額"
Rakuten Pay"利用日時", "決済金額"
SMBC"取引年月日", "お引き出し金額"
MUFG"日付", "摘要", "お支払い金額"
Vietcombank"Ngay GD", "So tien"
MB Bank"Ngày GD", "Giá trị"

Trả về null nếu không nhận diện được → không hiện banner AutoDetect.

6.2 detectColumnsFromCSV(csv: string): ColumnMapping

Phân tích file CSV và tự động tìm cột phù hợp. Trả về interface:

interface ColumnMapping {
  headers:   string[]        // tất cả tên cột
  dateCol:   string | null   // tên cột ngày
  descCol:   string | null   // tên cột mô tả
  amountCol: string | null   // null nếu dùng debit/credit riêng
  debitCol:  string | null   // tên cột ghi nợ
  creditCol: string | null   // tên cột ghi có
}

Người dùng ghi đè qua UI ColSelect → lưu vào userMapping (Partial<ColumnMapping>).

6.3 parseFile(file: File, provider: PaymentProvider, mapping?: Partial<ColumnMapping>): Promise<ImportResult>

interface ImportResult {
  success:      boolean
  transactions: Transaction[]  // giao dịch đã parse (kể cả khi có lỗi)
  errors:       string[]       // cảnh báo (không chặn import)
}

Xử lý encoding (thực hiện trong processFile() trước khi gọi parser):

Điều kiệnEncoding
Byte đầu là BOM UTF-8 (EF BB BF)UTF-8, bỏ BOM
Decode Shift-JIS có ký tự lạUTF-8
Mặc định (file JP)Shift-JIS

Sau khi có text sạch: gọi parseFile(f, activeProvider, userMapping). Kết quả: tất cả giao dịch được chọn mặc định (setSelected(new Set(res.transactions.map(tx => tx.id)))).

8. Luồng dữ liệu

Luồng xử lý file (processFile)

User kéo-thả / click chọn file
  → processFile(f: File)
    → setLoading(true), reset: result, error, confirmed, detected, mapping, userMapping, selected
    → setFile(f)
    → Đọc 4KB đầu → detect encoding (UTF-8 vs Shift-JIS)
    → Parse headers → autoDetectProvider(headers)
      → Nếu phát hiện provider khác: setDetected() → hiện AutoDetect banner
    → Nếu generic_csv: detectColumnsFromCSV() → setMapping()
    → parseFile(f, activeProvider, userMapping) → ImportResult
    → setResult(res)
    → setSelected(new Set(tất cả tx.id))   // mặc định chọn hết
    → setLoading(false)

Luồng xác nhận (handleConfirm)

User nhấn "Nhập N giao dịch"
  → handleConfirm()
    → toAdd = result.transactions.filter(tx => selected.has(tx.id))
    → addTransactions(toAdd)
      → Zustand: dedup theo id, append state
      → Supabase: upsert vào bảng transactions (fire-and-forget)
    → setConfirmed(true)
  → Banner thành công hiển thị

Luồng reset (handleReset)

handleReset()
  → setFile(null), setResult(null), setError(null), setConfirmed(false)
  → setDetected(null), setMapping(null), setUserMapping({})
  → setSelected(new Set())
  → fileInputRef.current.value = ''   // bắt buộc để input accept file mới

🟡 Upsert dùng id làm conflict key
addTransactions() dùng Supabase upsert. Nếu import cùng file 2 lần, ID giống nhau → row bị ghi đè (không tạo bản ghi mới). Đây là behavior mong muốn để tránh trùng, nhưng cần chú ý nếu parser sinh ID không deterministic.
🔴 ledger_id phụ thuộc vào currentLedger khi import
Nếu currentLedger là null tại thời điểm addTransactions() (race condition khi load), ledger_id sẽ là chuỗi rỗng ''. Có console.warn nhưng không chặn luồng import.
💡 source field nên ghi 'csv_import' thay vì 'manual'
Trang /categories dùng t.source để nhóm LinkedAccounts. Nếu import CSV ghi source = 'manual', dữ liệu sẽ bị nhóm nhầm vào "Nhập thủ công" thay vì "CSV Import".
