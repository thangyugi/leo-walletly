2. Tổng quan luồng import

Trang /import cung cấp quy trình nhập giao dịch từ file CSV hoặc PDF theo 2 bước:

Bước 1 — Setup (Thiết lập)

  1. Người dùng chọn khu vực (Nhật Bản 🇯🇵 / Việt Nam 🇻🇳 / Toàn cầu 🌐)
  2. Chọn nhà cung cấp phù hợp từ danh sách IMPORT_PROVIDERS
  3. Kéo-thả hoặc click để chọn file CSV / PDF
  4. Hệ thống tự động nhận diện provider từ header CSV → hiển thị banner gợi ý
  5. Nếu là generic_csv: hiển thị UI ánh xạ cột cho ngày/mô tả/số tiền

Bước 2 — Review (Xem trước)

  1. Bảng xem trước liệt kê tất cả giao dịch được parse
  2. Người dùng tick/bỏ tick từng giao dịch (mặc định: tất cả được chọn)
  3. SummaryStrip hiển thị tổng thu/chi/cân đối
  4. Nhấn "Nhập X giao dịch" → addTransactions() vào Zustand store + upsert Supabase
  5. Banner thành công xuất hiện, cung cấp nút "Nhập thêm" để reset
Lưu ý: Biến step được tính tự động: step = result && !confirmed ? 'review' : 'setup'. Không có state step riêng — nó phụ thuộc vào result và confirmed.

4. Các component

4.1 StepBar

Props: step: PageStep, file: File | null, provider: PaymentProvider, t: any

Thanh chỉ báo tiến trình gồm 2 bước: Thiết lập và Xem trước, nối bởi mũi tên ArrowRight.

Mỗi bước có trạng thái:

  • done (bước 1 đã hoàn tất): nền xanh nhạt, số được thay bằng ✓, hiển thị tên provider + tên file rút gọn
  • current (bước đang hoạt động): nền brand-600 (tím xanh), chữ trắng
  • upcoming: nền xám, chữ mờ

4.2 ProviderCard

Props: p: ProviderMeta, selected: boolean, onClick: () => void, lang: string

Card hiển thị thông tin một nhà cung cấp:

  • Avatar hình vuông màu thương hiệu, hiển thị chữ viết tắt (initials)
  • Tên provider (label)
  • Mô tả ngắn theo ngôn ngữ hiện tại (descVi / descJa / descEn)
  • Badges định dạng file hỗ trợ (CSV, PDF)

Khi được chọn: viền và nền theo màu thương hiệu của provider (p.color).

// Border + background khi selected:
style={selected ? { borderColor: p.color, backgroundColor: `${p.color}10` } : {}}

4.3 Tab khu vực (RegionTabs)

3 tab nằm ngang: 🇯🇵 Nhật Bản / 🇻🇳 Việt Nam / 🌐 Toàn cầu

Khi chuyển tab: lọc lại filteredProviders và tự động chọn provider đầu tiên trong danh sách.

Logic lọc:

const filteredProviders = IMPORT_PROVIDERS.filter((p) =>
  region === 'global' ? true : p.region === region || p.region === 'global'
)

Tab "Toàn cầu" hiển thị tất cả provider.

4.4 Khu vực kéo-thả file (FileDrop)

Vùng div lớn chiếm toàn bộ chiều ngang, hỗ trợ:

  • Click → mở hộp thoại chọn file (fileInputRef.current?.click())
  • Drag & Drop → onDrop lấy file từ e.dataTransfer.files[0]

3 trạng thái hình ảnh:

4.5 Banner tự động nhận diện (AutoDetect)

Hiển thị khi: detected !== null && detected !== provider (phát hiện provider khác với provider đang chọn).

Nội dung: icon Sparkles + thông báo provider được phát hiện + nút Xác nhận để áp dụng.

Nhấn Xác nhận: setProvider(detected); setDetected(null)

Hệ thống đọc 4KB đầu của file, phân tích headers CSV để tự động nhận diện — không cần người dùng chọn thủ công.

4.6 Ánh xạ cột CSV (ColSelect)

Chỉ hiển thị khi: mapping !== null && provider === 'generic_csv' && step === 'setup'

Component ColSelect: label + <select> native, options là tất cả headers của CSV.

3 trường ánh xạ:

  • Ngày (dateCol)
  • Mô tả (descCol)
  • Số tiền (amountCol) — hoặc nếu không có: Ghi nợ (debitCol) + Ghi có (creditCol)

Sau khi điều chỉnh: nhấn nút Parse lại → gọi reParseWithMapping().

Logic xử lý: userMapping ghi đè lên mapping (auto-detect), merge khi truyền vào parseFile().

4.7 Thông báo lỗi (ErrorBanner)

Hiển thị khi error !== null. Nền đỏ nhạt, icon AlertCircle.

Lỗi nhiều dòng được split bởi \n, mỗi dòng là một <p>.

Nút X đóng banner: setError(null).

Hiển thị khi: result && result.transactions.length > 0 && !confirmed

Bảng <table> có max-h-[400px] overflow-y-auto (cuộn dọc). Header cố định bằng sticky top-0.

4.9 Hàng xem trước (PreviewRow)

Props: tx: Transaction, checked: boolean, onToggle: () => void, t: any

Khi không được tick (!checked): opacity 40% — giao dịch sẽ không được import.

Badge loại:

  • Thu vào: TrendingUp + nền brand-50, chữ brand-700
  • Chi ra: TrendingDown + nền red-50, chữ red-600

Số tiền: xanh lá (text-brand-600) cho income, đỏ (text-red-500) cho expense.

4.10 Tóm tắt tài chính (SummaryStrip)

4 ô thống kê nằm ngang (grid chia 4, chia cách bằng đường dọc), hiển thị phía trên bảng:

4.11 Thanh chọn tất cả + đếm

Nằm giữa SummaryStrip và bảng. Gồm:

  • Checkbox chọn tất cả: 3 trạng thái — all checked (xanh đặc), partial (xanh nhạt + dấu −), unchecked (trắng)
  • Đếm: selectedCount / result.transactions.length đã chọn
  • Nút hiển thị số cảnh báo parse (nếu có), toggle showErrors
  • Nút Reset (góc phải): gọi handleReset()

Khi showErrors: vùng mở rộng hiển thị danh sách cảnh báo (nền amber-50, cuộn tối đa 112px).

4.12 Footer xác nhận import

Nằm dưới cùng của bảng xem trước. Responsive (flex-col trên mobile, flex-row trên tablet+).

Bên trái: thông báo số giao dịch sẽ được import, hoặc "Hãy chọn ít nhất 1 giao dịch".

Bên phải: nút Reset (secondary) + nút Nhập N giao dịch (primary, disabled khi selectedCount === 0).

Khi nhấn Nhập:

function handleConfirm() {
  const toAdd = result.transactions.filter((tx) => selected.has(tx.id))
  addTransactions(toAdd)   // Zustand store + Supabase upsert
  setConfirmed(true)
}

4.13 Banner thành công

Hiển thị khi confirmed === true. Thay thế hoàn toàn bảng xem trước.

Nền brand-50, icon CheckCircle2 màu brand-600.

Thông báo: "Đã nhập X giao dịch thành công!" + gợi ý xem Dashboard.

Nút Nhập thêm: gọi handleReset() để reset toàn bộ state.

6. Parser & tự động nhận diện

Module features/import/parsers.ts xuất 3 hàm chính:

6.1 autoDetectProvider(headers: string[]): PaymentProvider | null

Nhận mảng header CSV, so khớp với pattern đặc trưng của từng provider, trả về PaymentProvider hoặc null nếu không nhận diện được.

Ví dụ:

// PayPay thường có header "利用日","利用金額"
// SMBC có "取引年月日","お引き出し金額"
// Vietcombank có "Ngay GD","So tien"

Được gọi trong processFile() sau khi đọc 4KB đầu file (trước khi parse toàn bộ).

6.2 detectColumnsFromCSV(csv: string): ColumnMapping

Phân tích CSV và tự động nhận diện cột: ngày, mô tả, số tiền (hoặc debit/credit riêng).

Trả về ColumnMapping:

interface ColumnMapping {
  headers:   string[]
  dateCol:   string | null
  descCol:   string | null
  amountCol: string | null   // null nếu dùng debit/credit riêng
  debitCol:  string | null
  creditCol: string | null
}

Người dùng có thể ghi đè qua UI ColSelect → lưu vào userMapping.

6.3 parseFile(file: File, provider: PaymentProvider, mapping?: Partial<ColumnMapping>): Promise<ImportResult>

Hàm async chính: nhận File + provider + mapping tùy chọn, trả về ImportResult:

interface ImportResult {
  success:      boolean
  transactions: Transaction[]
  errors:       string[]       // danh sách cảnh báo (không chặn import)
}

Xử lý encoding:

  • Kiểm tra BOM UTF-8 (bytes: EF BB BF)
  • Nếu có BOM hoặc decode UTF-8 sạch → dùng UTF-8
  • Ngược lại → thử Shift-JIS (cho file CSV Nhật Bản)

PDF: xử lý bằng thư viện PDF.js hoặc tương đương, logic parse theo provider.

Lưu ý: Encoding detection được thực hiện trong processFile() (ở page.tsx), không nằm trong parser engine.

7. Luồng dữ liệu

Luồng xử lý file (processFile)

User chọn file
  → processFile(f: File)
    → Đặt loading = true, reset các state liên quan
    → Đọc 4KB đầu → detect encoding (UTF-8 vs Shift-JIS)
    → Parse header → autoDetectProvider(headers)
      → Nếu phát hiện provider khác: setDetected() → hiển thị banner
    → Nếu generic_csv: detectColumnsFromCSV() → setMapping()
    → parseFile(f, activeProvider, userMapping) → ImportResult
    → setResult(res)
    → setSelected(all tx ids)   // mặc định chọn tất cả
    → loading = false

Luồng xác nhận import (handleConfirm)

User nhấn "Nhập N giao dịch"
  → handleConfirm()
    → Lọc result.transactions theo selected (Set)
    → addTransactions(toAdd)
      → Zustand: thêm vào state (dedup theo id)
      → Supabase: upsert vào bảng transactions
    → setConfirmed(true)
  → Banner thành công hiển thị

Luồng reset (handleReset)

handleReset()
  → setFile(null)
  → setResult(null), setError(null), setConfirmed(false)
  → setDetected(null), setMapping(null), setUserMapping({})
  → setSelected(new Set())
  → fileInputRef.current.value = ''  // xóa input file

8. Kết nối Store (useTransactionsStore)

Trang import chỉ sử dụng 1 action từ store:

ActionKhi gọiHành vi
addTransactions(txns) Khi xác nhận import 1. Gắn ledgerId, workspaceId, organizationId từ currentLedger
2. Dedup theo id — không thêm giao dịch đã tồn tại
3. Append vào state.transactions
4. Async upsert vào Supabase bảng transactions
Dedup: addTransactions kiểm tra Set(existing ids) → chỉ thêm fresh transactions. Tránh trùng lặp khi import cùng file nhiều lần.
